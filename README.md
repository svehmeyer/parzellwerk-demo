# Parzellwerk – Testversion

Vereinsverwaltung für Kleingartenvereine, als Testversion zum Ausprobieren für Windows und Mac.
Die Installer liegen unter **Releases** (rechts auf dieser Seite).

**Enthalten:** Mitglieder, Gärten, Anlagen, Artikel, Zusatzkosten, Verträge, Karte und Auswertungen –
bis zu 25 Mitglieder. Beim ersten Start lässt sich ein erfundener Beispielverein anlegen.
Rechnungen entstehen als Muster-Vorschau mit Aufdruck.

**Nur in der Vollversion:** Rechnungen festschreiben, drucken und per E-Mail versenden, Rechnungslauf,
Zahlungen und offene Posten, Excel-Export, beliebig viele Mitglieder.

Die Testversion läuft getrennt von einer installierten Vollversion und arbeitet ohne Internet auf diesem Rechner.
